Your task is to write all reporting functionality within this class. Each method will be tested independently, and you must not alter the database schema or data.

Returns the total number of climbers currently registered in the database.

Time Conversion Utilities
Use the following helper functions to convert between minutes and HH:MM format:

def to_minutes(hhmm: str) -> int:
    h, m = map(int, hhmm.split(":"))
    return h * 60 + m

def to_hhmm(minutes: int) -> str:
    h = minutes // 60
    m = minutes % 60
    return f"{h:02}:{m:02}"
